\chapter{introdução}
\label{cap:introducao}

A introdução deve apresentar de forma clara e objetiva o escopo do projeto, contextualizando o problema que o software visa resolver. De acordo com as Diretrizes do PPC do Curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS), este capítulo deve abordar o tema central, a motivação para a escolha do projeto e os objetivos a serem alcançados.

% --- EXEMPLO DE CITAÇÃO INDIRETA ---
% A citação indireta reproduz a ideia do autor com suas próprias palavras.
Segundo \textcite{pressman_engenharia}, a engenharia de software é uma disciplina que se ocupa de todos os aspectos da produção de software, desde os estágios iniciais de especificação do sistema até a manutenção desse sistema após ele entrar em uso.

Conforme a ABNT NBR 14724, ``esta Norma especifica os princípios gerais para a elaboração de trabalhos acadêmicos (teses, dissertações e outros), visando sua apresentação à instituição'' \cite{pressman_engenharia}.

% --- EXEMPLO DE NOTA DE RODAPÉ ---
O desenvolvimento de software\footnote{Software é um conjunto de instruções que, quando executadas, fornecem características, funções e desempenho desejados \cite{pressman_engenharia}.} envolve diversas etapas que devem ser documentadas adequadamente.

\section{Problema}

Descreva detalhadamente o problema ou a oportunidade de melhoria que motivou o desenvolvimento do software. Explique o cenário atual, as dificuldades enfrentadas pelos usuários ou pela organização e por que uma solução tecnológica se faz necessária.

% --- EXEMPLO DE CITAÇÃO DIRETA LONGA (mais de 3 linhas) ---
% Citações com mais de 3 linhas devem ser destacadas com recuo de 4cm,
% fonte menor (10pt) e espaçamento simples, sem aspas.
\begin{citacao}
A engenharia de software é uma disciplina de engenharia relacionada com todos os aspectos da produção de software, desde os estágios iniciais de especificação do sistema até a manutenção desse sistema, depois que ele entrou em uso. Nessa definição, existem duas frases-chave: disciplina de engenharia e todos os aspectos da produção de software \cite[p.~39]{pressman_engenharia}.
\end{citacao}

\section{Objetivos}
Nesta seção devem ser apresentados os objetivos do projeto, indicando de forma clara o que se pretende alcançar com o desenvolvimento do software. Os objetivos devem ser coerentes com o problema de pesquisa, delimitar o escopo do trabalho e orientar todas as etapas de desenvolvimento e avaliação da solução proposta.
\subsection{Objetivo Geral}
Apresente o objetivo geral do projeto. Deve ser uma frase clara, iniciando com verbo no infinitivo, que resuma o propósito principal do software (ex: Desenvolver um sistema web para gerenciamento de...).

\subsection{Objetivos Específicos}
Liste os objetivos específicos que, somados, permitirão alcançar o objetivo geral:
\begin{itemize}
    \item Realizar o levantamento de requisitos com os usuários finais;
    \item Modelar o banco de dados relacional para armazenamento das informações;
    \item Implementar os módulos de cadastro e relatórios;
    \item Realizar testes de usabilidade e validação do sistema.
\end{itemize}

\section{Justificativa}

Apresente os motivos que justificam o desenvolvimento deste software. A justificativa deve responder à pergunta: ``Por que este projeto é importante?''. Podem ser abordados aspectos técnicos, sociais, acadêmicos ou econômicos.
